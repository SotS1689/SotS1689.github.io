# taylordrummond.org

Home page linking all of Taylor Drummond's tools. Plain HTML, no build step.

- Open `index.html` in a browser to run locally.
- Deployed by GitHub Pages from the `main` branch of `SotS1689/SotS1689.github.io`.
- The `CNAME` file sets the custom domain. Because this is the user site, every
  project site (DA-Tool, lets-sing, ...) is also served at `taylordrummond.org/<repo>/`.
